# auto-modelo

Un mod para Claude Code (en español) que elige solo el modelo según lo difícil que sea tu pedido:
Haiku para lo fácil, Sonnet para el trabajo normal y Opus 5.5 para lo difícil.

- Panel "Modelos en uso" junto al chat, con monitos animados por modelo y una mascota que reacciona.
- Muestra el ahorro estimado de tokens frente a usar solo Opus 5.5.

## Instalar

```bash
claude plugin marketplace add MatiasFP/auto-modelo
claude plugin install auto-modelo@auto-modelo
```

Después escribe `/automodelo` en el chat para abrir el panel.
